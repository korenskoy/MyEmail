============================================================================
GPL-3.0 isolation note
============================================================================

This XPC service (MUAResolver.xpc) is a separate executable bundle and is
launched in a separate process from the MyEmail host application. The host
application and this service communicate only through a narrow Swift
protocol (MUAResolverProtocol) over NSXPCConnection. No code or data from
this bundle is statically or dynamically linked into the MyEmail binary.

Per the FSF's own guidance on "mere aggregation" and process-separated
components (https://www.gnu.org/licenses/gpl-faq.html#MereAggregation),
the MyEmail host application is NOT a derivative work of dispmua and
therefore is not subject to the GPL-3.0. Only this XPC service bundle is.
